# 🌐 Personal Profile Website — Shivamraj Matkar

A modern, responsive personal portfolio website created as part of **Assessment – Task 1: Personal Profile Website (AI Based)** for the InAmigos Foundation.

The website introduces my background, showcases my technical skills, organises my projects by development area, and highlights my achievements and learning milestones.

## 👨‍💻 About Me

Hi, I'm **Shivamraj Matkar**, an Information Technology student at Pimpri Chinchwad College of Engineering (PCCOE), Pune.

I am passionate about technology, software development, and building practical solutions. I am continuously improving my programming skills and exploring web development, machine learning, and the Internet of Things (IoT).

My goal is to turn ideas into useful digital experiences through continuous learning and hands-on projects.

## ✨ Features

- **Hero Section:** Introduction, profile photograph, and navigation to important sections.
- **About Me:** A concise overview of my interests, learning journey, and goals.
- **Technical Skills:** A categorised display of programming, web development, data science, and IoT skills.
- **Project Library:** Projects organised into three categories:
  - Web Development
  - Machine Learning
  - IoT Development
- **Project Cards:** Each card can display a project image, title, description, and technologies used.
- **Add Project Feature:** A form to add projects to the relevant category.
- **Achievements & Milestones:** A section for recording projects, courses, certificates, competitions, and learning progress.
- **Contact Section:** Quick access to email, LinkedIn, and GitHub.
- **Responsive Design:** Layout adapted for desktop, tablet, and mobile screens.
- **Animations:** Subtle scroll-reveal effects and interactive hover transitions.
- **Data Export:** Download locally stored project and achievement information as a JSON file.

## 🚀 How to Run the Website

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Explore the sections and test the project and achievement forms.

## ➕ Managing Projects and Achievements

The website includes forms for adding projects and milestones.

To add a project:

1. Open the **My Work** section.
2. Select Web Development, Machine Learning, or IoT Development.
3. Click **Add Project**.
4. Enter the project title, image path, description, skills used, and optional project link.
5. Save the project.

To add an achievement, enter its title, type, date, and description in the Achievements section.

**Important:** These entries are stored in the current browser's local storage. They do not automatically appear for other website visitors. To publish new entries for everyone, update the project data in `script.js` and redeploy the website. A backend such as Firebase or Supabase can be integrated for online project management.

## 🎨 Design Approach

The website follows a clean, modern, and professional visual style featuring:

- A soft green and blue colour palette.
- Compact sections with clear visual hierarchy.
- Rounded cards and subtle shadows.
- Horizontal project-category navigation.
- Responsive layouts for different screen sizes.
- Minimal animations to improve the browsing experience.
