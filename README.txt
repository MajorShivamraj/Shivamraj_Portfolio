SHIVAMRAJ MATKAR PORTFOLIO V2

Files: index.html, style.css, script.js. Keep them in the same folder. Open index.html or use VS Code Live Server.

Photo: replace the portrait placeholder in index.html with <img src="assets/profile.jpg" alt="Shivamraj Matkar"> and add your portrait to an assets folder. Replace LinkedIn/GitHub URLs.

Project cards: use Add project to create a card with image, title, description, and comma-separated skills. You can scroll horizontally across Web, ML, and IoT tracks.

Important: Add project and Add milestone save to localStorage in this browser only. They do NOT automatically update the public website for other visitors. Export my data downloads a JSON backup. To publish new entries for everyone, add them to seedProjects / seedAchievements in script.js and redeploy. For a live online admin dashboard, connect Firebase or Supabase.
